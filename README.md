
# AWS EC2 Windows Server Setup

## Project Overview
Created and successfully connected to a Windows Server EC2 instance on AWS using Remote Desktop Protocol (RDP).

## Services Used
- Amazon EC2
- Windows Server
- AWS Key Pair
- Remote Desktop Protocol (RDP)

## Steps Performed
1. Launched a Windows Server EC2 instance.
2. Configured the EC2 instance.
3. Retrieved the Windows Administrator password.
4. Connected to the Windows Server using RDP.
5. Successfully accessed the Windows Server desktop.

## Result
Windows Server was successfully created and accessed through RDP.
